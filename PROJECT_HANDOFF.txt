Build Commands
--------------
Install dependencies:

  npm install

Generate the static production build:

  npm run build:github

This generates the current static files in dist/.

Preview the static build:

  npm run preview

Run development mode:

  npm run dev

Run lint:

  npm run lint

Deployment Folders
------------------
- dist/
  Fresh output generated by npm run build:github.
- s3-build/
  Static files prepared for AWS S3 and CloudFront.
- docs/
  Static files prepared for GitHub Pages. docs/USER_MANUAL.md is preserved.

AWS S3 / CloudFront Procedure
-----------------------------
1. Run: npm run build:github
2. Upload the contents of s3-build/ to the S3 bucket root.
3. Do not upload the s3-build folder itself.
4. Set index.html as the default/index document.
5. Set 404.html as the error document.
6. For CloudFront, set the default root object to index.html.
7. Configure custom error responses for 403 and 404 to return /404.html.
8. Invalidate the CloudFront cache after a new upload:

   aws cloudfront create-invalidation --distribution-id YOUR_DISTRIBUTION_ID --paths "/*"

For a private S3 bucket, use CloudFront Origin Access Control. Do not commit AWS credentials.

GitHub Pages Procedure
----------------------
1. Run: npm run build:github
2. Synchronize or commit the generated docs/ files.
3. Push the changes to the GitHub repository.
4. In GitHub, open Settings > Pages.
5. Choose Deploy from a branch.
6. Select the publishing branch and /docs folder.
7. Save and wait for GitHub Pages to deploy.
8. Hard-refresh the website after deployment if cached assets are visible.
